# 玩家控制与影迹系统使用文档

适用版本：Unity **2022.3.62f3c1**，2D URP，传统 Input Manager。无需安装额外运行时包。

## 1. 快速开始

1. 等待 Unity 导入资源并完成脚本编译。
2. 打开 `Assets/ShadowTrace/Scenes/ShadowTraceDemo.unity`，点击 **Play**。也可以使用菜单 **Tools → Shadow Trace → Open Demo Scene**。
3. 如果场景或预制体缺失，运行 **Tools → Shadow Trace → Create Demo Assets**，再打开场景。
4. 点击 Game 窗口，让键盘输入进入游戏。

演示场景中的玩家、地面、墙壁、平台和箱子在进入 Play 时生成，退出 Play 后恢复。原始 `SampleScene` 保留。演示场景不包含胜利条件、机关或玩家死亡重生逻辑。

演示场景已列为 Build Settings 的首个场景。重建演示资源前，请保存当前未命名场景；该菜单保留已有预制体配置，但会覆盖演示场景。

## 2. 键位

| 按键 | 功能 |
|---|---|
| A / D | 左右移动；同时按下视为没有水平输入 |
| 左右 Shift | 按住疾跑 |
| Space | 在地面或停止的趋近型影子上跳跃；无二段跳 |
| E | 开始准备；准备中取消；录制中提前结束 |
| 1–8（主键盘） | 选择对应编号的影子，选中后显示黄色；空编号取消选择 |
| R | 删除当前选中影子 |
| 连按两次 R | 清除所有影子，无需选择 |

R 的双击窗口默认 **0.3 秒**。单击删除在窗口结束后执行；删除目标取第一次按 R 时选中的影子，之后改选不会改变此次删除目标。清除影子不会取消正在进行的准备或录制。

## 3. 影迹流程与分类

按 E → **3 秒准备** → **最多 6 秒录制** → 生成一个影子。

- 准备期间可以正常操作，再次按 E 会取消整轮准备。
- 准备结束时保存玩家位置，作为本轮生成起点。
- 录制期间仍可正常移动、疾跑和跳跃，再按 E 可提前结束；到 6 秒自动结束。
- 一次只能准备或录制一个影子，结束后没有额外冷却。
- 最多同时存在 8 个影子，满员时不能开始准备。
- 分类使用 **A/D 输入意图**，不是实际位移。按住 D 撞墙仍算向右移动；原地跳跃不改变分类。

分类按以下优先级进行：

| 类型 | 录制动作 | 例子 |
|---|---|---|
| 回避型 Avoid | 发生过左右反向，优先于其他规则 | 按 D，再按 A；之后即使停下仍为回避型 |
| 跟随型 Follow | 有移动、没有反向，结束前连续停止至少 0.3 秒 | 按 D 一段时间，松开，等至少 0.3 秒后按 E |
| 趋近型 Approach | 有移动、没有反向，结束时停止不足 0.3 秒 | 持续按 D，按 E 结束或等录制自动结束 |
| 停留型 Stay | 全程没有有效水平输入 | 不按 A/D，等待结束或按 E |

中途停顿后继续同向移动不会自动成为跟随型；只判断结束前的连续停止时间。首次有效移动方向用于趋近型与回避型的初始方向。录制不是轨迹重播，影子不会重播玩家疾跑和跳跃。

## 4. 四类影子的效果

### 停留型

在录制起点的地面上生成并固定不动。录制起点悬空时向下搜索地面；因此只原地跳跃也可以产生停留型，但会定位到地面而非悬在空中。搜索范围默认 20 单位；找不到地面或生成空间被实体占用时生成失败，不占用编号。

### 趋近型

从录制起点沿首次移动方向，以玩家普通移动速度持续前进。

- 遇到带 `PushableBody2D` 的可推动动态物体，会推动它。
- 遇墙壁、未标记为可推动的障碍、锁定水平移动的箱子，立即停止。
- 持续推不动的箱子也会使影子停止；默认受阻判定时间 0.4 秒。
- 停止后永久锁定水平位置，仍受重力影响，障碍移开也不继续走。
- 移动期间玩家可以穿过它；停止后开启与玩家的实体碰撞，可跳上去作为平台。
- 停止时若与玩家重叠，等玩家走出影子后才开启碰撞。
- 没有悬崖保护，可能从边缘掉落。

### 回避型

从录制起点沿首次移动方向前进，接近阻挡物时反向，形成往返。它不会停下来变成玩家平台；没有寻路、自动跳跃或悬崖保护。默认反向间隔 0.2 秒，避免贴墙连续翻转。

### 跟随型

在录制起点生成，保存此时“影子位置减玩家位置”的二维偏移，之后追赶“玩家当前位置加偏移”。会跟随玩家上下移动，但受墙壁阻挡；解除阻挡后继续追赶目标。最大追赶速度默认 10，不保证瞬时恢复距离，不会自动绕路。

影子之间互不阻挡。除停止后的趋近型外，玩家与影子互不阻挡。所有影子都保留与场景实体的碰撞。

## 5. 编号与生命周期

影子持续存在，直到被删除、外部逻辑销毁或卸载场景；没有自动消失时间。编号从 1 开始，使用最小空闲编号：生成 1、2、3，删除 2，下一个生成的影子使用 2，原来的 3 不改变。

选中影子变成黄色，头顶显示编号和类型；停止的趋近型额外显示 `[Platform]`。界面使用英文，避免默认 GUI 字体缺少中文字符；类型对照见上表。

## 6. 接入自己的关卡

1. 拖入 `Assets/ShadowTrace/Prefabs/Player.prefab`。
2. 创建空对象，添加 `ShadowManager`；将场景玩家拖到 **Player**，将 `Shadow.prefab` 拖到 **Shadow Prefab**。
3. 将该管理器拖到玩家 `ShadowTraceAbility` 的 **Manager**。
4. 创建 HUD 对象，添加 `ShadowTraceHUD`，关联玩家的能力组件和管理器。
5. 为相机添加 `TraceCameraFollow`，将 **Target** 关联到玩家；使用正交相机。
6. 地面和墙壁添加非 Trigger 的 `Collider2D`；静态地形无需刚体。
7. 用 `PushableBox.prefab` 放置可推动箱子，或为已有箱子添加动态 `Rigidbody2D`、实体碰撞体及 `PushableBody2D`。

请勿同时在自己的关卡挂 `ShadowTraceDemo`，否则它会额外创建演示玩家和场景。

预制体默认采用居中的 `BoxCollider2D`，尺寸为 0.8 × 1.4，缩放为 1，刚体不旋转。更换视觉资源可以保留物理尺寸；生成检测要求保持居中碰撞体与无旋转结构。修改尺寸时同步更新 SpriteRenderer 显示尺寸，避免视觉和碰撞不一致。

### Inspector 参数

| 组件 | 参数 | 默认值 / 用途 |
|---|---|---|
| PlayerController2D | Walk Speed / Sprint Speed / Jump Speed | 4 / 7 / 10 |
| PlayerController2D | World Mask | 默认所有层；决定地面检测范围 |
| ShadowTraceAbility | Preparation Duration / Recording Duration | 3 / 6 秒 |
| ShadowTraceAbility | Stop Threshold | 0.3 秒，跟随型结束停止阈值 |
| ShadowManager | Ground Search Distance | 20，停留型向下找地距离 |
| ShadowManager | Double Click Window | 0.3 秒 |
| ShadowActor | Obstacle Distance | 0.08，前方障碍检测距离 |
| ShadowActor | Reverse Interval | 0.2 秒 |
| ShadowActor | Blocked Duration | 0.4 秒，推不动物体时的停止阈值 |
| ShadowActor | Push Force | 35，推动力 |
| ShadowActor | Follow Speed / Follow Dead Zone | 10 / 0.025 |
| ShadowActor | World Mask | 默认所有层；用于障碍和生成检测 |
| PushableBody2D | Maximum Horizontal Speed | 4，额外推动力的速度上限 |

预制体默认重力倍率 3、玩家质量 1、影子质量 4、箱子质量 1。推动是否成功受质量、摩擦、约束和外部障碍影响。`Maximum Horizontal Speed` 限制额外施力，不是对所有外部碰撞速度的硬限制。

World Mask 是查询范围，Unity 的 Physics 2D Layer Collision Matrix 仍决定实体碰撞。若限制玩家的地面检测层，请包含停止后的影子所在层，否则玩家站上影子后无法跳跃。玩家和影子之间的例外通过逐对 `IgnoreCollision` 管理，不需要修改全局层设置。

### 后续接入影子专属机关

在机关触发逻辑里用 `other.GetComponentInParent<ShadowActor>()` 判断影子，用 `Kind` 判断类型、`Number` 判断编号、`Stopped` 判断趋近型是否停止；玩家识别使用 `PlayerController2D`。只有影子可以操作的机关仅接受 `ShadowActor`。Trigger 不参与墙壁、地面和生成占用检测。

## 7. 验证方法

本次已在 Unity 2022.3.62f3c1 的隔离副本中完成编译和无图形批处理验证，**18 项自动测试全部通过**：8 项 EditMode、9 项行为与物理 PlayMode、1 项演示场景启动测试。键盘输入手感和画面显示请按下方步骤在 Game 窗口验收。

打开 **Window → General → Test Runner**：

- **EditMode**：验证四类分类、停止阈值、反向优先级、8 个上限和空号复用。
- **PlayMode**：验证趋近型推动物体、停止后永久保持水平位置、玩家可站立；验证回避反向、跟随受阻后恢复和停留型地面定位。
- **演示启动测试**：验证实际演示场景中的玩家、影子预制体、管理器、相机、界面和箱子引用，以及玩家落地。

手动额外验证：准备期间按 E 取消；录制提前结束和满时自动结束；生成 8 个后按 E；数字键选择、单击 R 删除、双击 R 清空；在墙边与玩家重叠时生成趋近型，确认停止后不会将玩家弹飞，离开后可以跳上影子。

## 8. 文件结构与常见问题

- `Assets/ShadowTrace/Runtime`：控制、分类、管理、物理行为、HUD 和演示逻辑。
- `Assets/ShadowTrace/Editor`：演示资源生成菜单，重建时保留已有预制体配置，但重建演示场景。
- `Assets/ShadowTrace/Prefabs`：玩家、影子、箱子。
- `Assets/ShadowTrace/Scenes`：演示场景。
- `Assets/ShadowTrace/Tests`：EditMode 与 PlayMode 测试。

**运行 SampleScene 没有玩家：** 打开新的 `ShadowTraceDemo` 场景。

**无法生成影子：** 查看提示；数量可能达到上限，录制起点可能被箱子或墙壁占据，停留型也可能找不到地面。

**影子穿过墙：** 检查墙壁不是 Trigger、Layer Collision Matrix 允许碰撞、碰撞体与渲染尺寸相符。

**箱子不被推动：** 检查有 `PushableBody2D`、刚体为 Dynamic、未 Freeze Position X；箱子后方被挡时趋近型最终停止，这是预期行为。

**停止的趋近型暂时不能站立：** 若玩家与其重叠，需要先走出去，让碰撞安全开启。

**按键无响应：** 点击 Game 窗口；Player Settings 中 Active Input Handling 需保留 Input Manager 或 Both。
