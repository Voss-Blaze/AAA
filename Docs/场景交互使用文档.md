# 场景交互使用文档

适用场景：`Assets/Scenes/SampleScene.unity`。直接打开并 Play 即可；交互资源已保存，无需每次运行配置工具。

## 1. 规则与开关图片

| 物品 | 关闭图片 | 开启图片 | 交互对象 |
| --- | --- | --- | --- |
| 按钮 | PressurePlate1 | PressurePlate2 | 仅影子从上方按压 |
| 路灯 | light1 | light2 | 仅影子触碰 |
| 大门 | door1 | door2 | 影子机关提供解锁条件，玩家接触后按 F 通行 |
| 地刺 spike1 | 使用现有图片 | 不切换图片 | 仅玩家触碰死亡 |

Prefab 名称表示提供哪张状态图片，不代表运行时一开始就已触发。按钮和路灯在新场景运行时从关闭状态开始；门由实际绑定按钮的状态决定图片。

## 2. 按钮与门联动

按钮根对象挂 `ShadowPressurePlate` 和非 Trigger 的 `BoxCollider2D`，提供固定支撑面；子对象 `Press Area` 是顶部的 Trigger 检测区。

默认支撑面放在中央按钮顶部，收窄宽度以避开两侧装饰柱；开关图片切换不会改变该支撑面。需要不同大小或形状时，可直接调整根碰撞体与 Press Area。

Inspector 设置：

- **Mode = Sustained**：持续型。至少有一个影子在上方按压才开启；最后一个影子离开、被禁用或删除后关闭。
- **Mode = Latched**：短暂型。影子按压一次后保持开启，直到重新加载场景。
- **Target Door**：该按钮控制的大门，直接拖入带 `InteractiveDoor` 的场景对象。
- **Closed Sprite / Active Sprite**：分别为 PressurePlate1 / PressurePlate2 的精灵。

任何类型影子都能按压。检测要求影子脚底接近支撑面顶部，中心位于按钮宽度内，并且没有向上起跳；玩家、侧面擦碰和上升中的跳跃不会触发。多个影子共用持续按钮时，只要仍有一个有效按压者就保持开启。

多个按钮可指向同一扇门，也可混合持续型与短暂型。门的 **Requirement Mode** 设置为：

- **All**：默认，所有绑定按钮必须有效。短暂型需要已触发，持续型需要当前有影子按住。
- **Any**：任意一个绑定按钮有效即可。

没有绑定按钮的门允许直接按 F 通行。禁用或销毁按钮不会被视为已满足条件。改绑按钮时，下一次物理更新会将其从旧门移到新门。

SampleScene 已将现有按钮绑定到现有门，默认 Sustained / All；可以在 Inspector 改为 Latched，或复制按钮并绑定到同一个门。复制按钮时按地形调整支撑面及 Press Area；检测范围不随开关图片自动改变。

## 3. F 通行与防夹保护

门根对象的非 Trigger `BoxCollider2D` 提供实体阻挡，子对象 `Interaction Area` 检测玩家是否接触门。其范围应包住阻挡体并稍微向外扩展。

1. 按钮满足组合条件时，门立即显示 door2 打开图片，但仍保持碰撞阻挡。
2. 玩家进入交互区域，HUD 提示按 F；条件不足时提示机关未满足。
3. 玩家按 F 后，临时忽略该玩家与门阻挡体之间的碰撞，玩家自行移动穿过门；不传送、不切换关卡。
4. 同时清空所有影子，并调用 `ShadowTraceAbility.CancelTrace()` 取消准备 / 录制，防止清空后又自动生成。
5. 持续按钮释放后门可以显示 door1，但本次玩家通行权限保持到玩家离开交互范围。随后恢复碰撞，下次仍须满足机关条件并按 F。

只对获得权限的玩家解除碰撞，影子不能按 F 获得通行权限。停留在区域内不会重复清理影子；离开后可进行下一次交互。门被禁用时也会释放碰撞例外。

门 Inspector 可设置玩家引用、Interaction Area、组合条件及两种精灵。运行时没有指定玩家时会寻找场景玩家；配置工具会明确绑定 SampleScene 玩家。

## 4. 路灯

`ShadowLamp` 使用 Trigger，仅接受影子触碰。首次触碰后 `IsLit` 为 true，精灵切换为 light2，影子离开或被删除也保持点亮。

此版本只切换图片，不写硬盘存档，不移动出生点，不增加实际灯光组件。重新加载场景后恢复未点亮状态。Inspector 可配置 Unlit Sprite / Lit Sprite。

## 5. 地刺与死亡

`SpikeHazard` 使用 Trigger，只接受带 `PlayerController2D` 的玩家；影子不会死亡。

玩家的 `PlayerLife.Die()` 只执行一次：取消录制、停用玩家操作与影子管理输入、停止玩家刚体模拟和动画，立即将 `Time.timeScale` 设为 0。随后用不受暂停影响的时间播放红色闪烁 / 淡出，默认 **Effect Duration = 0.6 秒**。

HUD 显示死亡与暂停提示。现有影子保留在暂停画面，不提供复活、重新开始菜单或路灯存档。编辑器停止 Play 后可重新运行；卸载或销毁死亡玩家时恢复死亡前的时间倍率，避免后续运行仍处于暂停。

## 6. 配置工具与资源

菜单 **Tools → Shadow Trace → Configure Scene Interactions** 会：

- 配置 spike1、light1 / light2、PressurePlate1 / PressurePlate2、door1 / door2 预制体。
- 为玩家预制体及 SampleScene 玩家添加 PlayerLife。
- 为 SampleScene 配置碰撞区域、HUD、玩家引用和默认按钮目标。
- 保留地图摆放、已有按钮模式、已有目标和自定义实体碰撞体，不重复添加组件。

工具会提示保存当前场景，然后保存配置；现有场景布局不会被演示场景覆盖。首次配置使用精灵物理轮廓的包围盒设置碰撞范围，减少透明留白带来的误触。

运行脚本为 PlayerLife、SpikeHazard、ShadowLamp、ShadowPressurePlate、InteractiveDoor；SceneInteractionSetup 仅在编辑器使用。原有移动、影迹分类和共用角色动画保持兼容。

## 7. 验收

2026-10-14 在 Unity `2022.3.62f3c1` 隔离副本运行 **14 项 EditMode + 39 项 PlayMode，共 53 项全部通过**。图形模式已检查关闭 / 开启图片与死亡着色预览；真实暂停中的死亡效果由运行测试验证。键盘操作和实验关卡布局仍可在 Game 窗口手动验收。

在 Test Runner 中运行 EditMode 和 PlayMode。交互测试覆盖开关资源绑定、场景引用、玩家 / 影子权限、顶部按压、最后一个影子释放、短暂型保持、All / Any 条件、F 的距离与锁定限制、通行防夹、清空影子、取消准备和录制，以及暂停后的死亡淡出。

Game 窗口手动检查：将影子放到按钮上，观察按钮与门切换图片；控制玩家接近门并按 F 穿过；确认影子消失后持续门关图但玩家不会被夹住。将按钮改为 Latched 后重复，门应在影子消失后仍保持打开图片。分别用玩家和影子接触路灯、地刺，检查权限与死亡画面。
